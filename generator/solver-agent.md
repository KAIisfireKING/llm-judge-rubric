# 数模求解（生成器）

> 本技能是从一套成熟的国赛论文自动生成方法论移植到终端的版本。**完整、权威的逐章规范在 `references/论文方法论.md`**——那是本技能的主体，动手前必须通读一遍并严格照做。本文件只给"在终端里怎么跑"的操作层与几条不可违反的红线。

## 定位（一句话）

**输入**：`题目/`（赛题 PDF/DOCX）+ `数据/`（附件 xlsx/docx）。
**输出**：`求解/`（每题的 Python、图、结果 csv）+ `论文/`（整篇 .tex + 编译好的 论文.pdf）。
**过程**：读题 → 求解计划 → 逐题求解 → 写论文 → 编译 → 排版优化，一气呵成。

## 开工前必读

1. **通读 `references/论文方法论.md`**。里面有：项目结构、六步执行流程、摘要字数硬约束、每章逐条规范、九宫格流程图模板、表格 longtable 列宽通式、代码规范（先算后画、只用 matplotlib、跨平台中文字体、公共头部）。**这些不是建议，是评委雷区，逐条照做。**
2. 确认工作目录下有 `题目/ 数据/ 求解/ 论文/` 四个目录；`论文/` 里要有模板 `format.cls`、`fonts/`、以及 0~10 各章的 .tex 骨架（新题从模板复制，见操作手册的"新题初始化"）。

## 终端里的三条硬规矩（补充方法论，不覆盖）

1. **每个 Python 脚本前两行固定加**（否则 Windows 下中文输出全乱码）：
   ```python
   import sys, io
   sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')
   ```
2. **编译命令**（2026-07-15 更正：TinyTeX 已从本机消失，现在**全机唯一 TeX 是 PATH 里的 MiKTeX 25.12**，直接裸写 `xelatex` 即可，已实测 0 错误）：
   ```bash
   cd 论文 && xelatex -interaction=nonstopmode 论文.tex && xelatex -interaction=nonstopmode 论文.tex
   ```
   工程里若有 `论文/build.py`（一键两遍编译+自动验收），优先用 `python -X utf8 论文/build.py`。
   编译后 `论文.log` 里 `Error` 数必须为 0；清 `Overfull`/`Underfull` 时**只允许**方法论 Step 5 的手段（微调文字、加 `\clearpage`），**禁止**用改表格环境类型（longtable→table）、改图宽（0.8\textwidth→\linewidth）、换字体这类"消警告但毁版面"的暴力手段——25-C 实测这么干版面全毁。
   > MiKTeX 已设缺宏包自动安装（`initexmf --set-config-value="[MPM]AutoInstall=1"`），非交互会话不会再因缺包弹窗卡死。模板等宽字体用 Windows 的 Consolas（format.cls 第 105–106 行）；正文中文字体必须走工程 `fonts/` 里的思源宋体（`\setCJKmainfont[Path=./fonts/,...]`），否则 PDF 文本层会坏。禁止下载/安装 tectonic、TinyTeX 等任何其他引擎。
3. **中文路径**：终端里对含中文的路径，尽量用工具的原生绝对路径读写；bash 里用变量拼接中文路径容易乱码，能直接写全路径就直接写。

## 运行方式（自主，但留复盘点）

- 生成阶段**自主跑完**：从读题到编译 PDF 中间不要停下来问"要不要继续"。遇到决策点（模型选型、参数取值）自行选当前最优并记录理由，继续往下。
- 但**每题求解脚本跑通、每次编译**后，把关键数值（min/max/mean/std、最优解、目标值）打印出来——这些既供论文引用，也是后面《数模论文严格评审》做"论文↔代码一致性"核对的证据。**结果表必须由代码产出的 csv 生成，不要手工誊写数字**（手工誊写是评审红线的高发区）。

## 关于九宫格流程图（一个明知故犯的取舍）

方法论 5.X.1 节要求每题画一张"固定 9 框流程图"。**保留它、照模板画**——这是本生成器的既定风格，也是照方法论办事。
⚠️ 但要知道：独立的《数模论文严格评审》技能会把"三张同构九宫格流程图"判为**模板化/AI 味**并在维度六扣分。这是两个技能之间一个**已知的、我们主动接受的冲突**：生成阶段先按模板产出，是否精简留到评审后由人(总大脑)决定，不在生成阶段纠结。

## 边界

- 本技能**不自评、不打分**。生成完就交给《数模论文严格评审》独立审。
- 本技能**不改别人的论文**（那是拿到评审报告后的修复动作）。它只负责"从零造一篇"。
